# NEON RUSH — Racing Game

A mobile-friendly arcade racing game made with HTML, CSS and JavaScript.

## Play
Open `index.html` in a browser. Enable GitHub Pages in Settings → Pages to publish it online.

## Controls
- LEFT / RIGHT: steer
- BRAKE: slow down
- GAS: accelerate
- NITRO: temporary speed boost
- Collect gold coins and avoid traffic.

Designed for touch screens and iPad.
